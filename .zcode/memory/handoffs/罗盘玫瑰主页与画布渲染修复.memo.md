## Decisions

- 主视觉最终定为罗盘玫瑰、固定方位不旋转——用户在锐利✦ → 萌系团子 → 球形星体多轮迭代后选定罗盘形象,并明确要求去掉自旋
- 方位光用预烘焙贴图(blur 烘焙进离屏画布)而非逐帧渐变光楔——消除宽度方向的可见梯度带,且每帧成本更低
- 光效一律加法混合渐变(lighter + rgba 渐变),非描边图形;图层顺序:星尘→流星→光晕→光芒→罗盘→碎星带→迸发
- 深空金星光主题,背景流线与浅色几何拼贴方案均被用户否定后移除
- 动画循环暂停条件用 IntersectionObserver,不用 document.hidden(内嵌浏览器恒 true)

## Pitfalls

- 内嵌浏览器 `document.hidden` 恒 true:动画循环别用它做暂停条件,否则循环刚启动就退出、画布全空
- Edit 写入中途浏览器 reload 会读到残缺文件,产生假错(如 `crossBeam is not defined`)——诊断前先带时间戳参数强制重载再下结论
- `canvas.width` 赋值即清空画布:resize 守卫必须只在尺寸真变时赋值,否则标题图渐进加载引发的滚动条抖动会把罗盘每帧擦掉
- python/python3 是 Windows Store 占位程序(退出码 49),本机无 Node;本地预览用 `.serve.ps1`(PowerShell TcpListener,端口 8645)
- PowerShell 预览服务器单线程:未完整请求会阻塞 ReadLine 冻死整个服务——卡死就 `taskkill //F //PID <pid>` 后重启
- 上下文压缩后凭记忆写 Edit 的 old_string 会失配——先 sed/grep 读文件真实内容再编辑
